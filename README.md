# TaskFlow — JavaScript Task Manager

A responsive task manager built with vanilla JavaScript. The project demonstrates DOM manipulation, array methods, filtering, search, event handling and browser localStorage.

## Live Demo

🔗 [View Live Demo](https://dinisch.github.io/javascript-task-manager/)

## Features

- Add and delete tasks
- Mark tasks as completed or active
- Filter by All / Active / Completed
- Search tasks instantly
- Clear completed tasks
- Automatic task counters
- Data persistence with localStorage
- Responsive layout for desktop and mobile
- Accessible labels and keyboard-friendly controls
